# Analysis / 统计复算

Run `python analysis/recompute.py` from the repository root after installing requirements. It verifies the raw JSONL hash, all 200 paired batches, Kaggle CSV, and recomputes metrics and uncertainty.

安装 requirements.txt 后，在仓库根目录运行 `python analysis/recompute.py`。脚本校验原始 JSONL 哈希、200 组完整配对与 Kaggle CSV，并重新计算指标和不确定性。
